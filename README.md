# ChatBot App 💬

This ChatBot app is a simple yet powerful tool that allows users to interact with a virtual assistant for various tasks. From answering basic questions to providing helpful information, this ChatBot app is designed to make your life easier. 🤖

## Features 🌟

- User-friendly interface for seamless communication
- Light and dark theme options
- Support for multiple languages
- Secure encryption for sensitive data

## Roadmap 🛣️

- Light and dark theme: ✔️ Done
- Support for multiple languages: ✔️ In Progress
- Password encryption for API key: ❌ Not Implemented Yet
- More chatrooms support: ❌ Not Supported Yet

## Build Instructions 🔨

### For Node.js Runtime Environment 🚀

1. Make sure you have Node.js runtime environment installed.
2. Clone this repository to your local machine

```shell
git clone https://github.com/yourusername/ChatBotApp.git
```

3. Install the necessary dependencies using bun

```shell
bun install
```

4. Run the app in development mode

```shell
bun run dev
```

## Usage 🚀

1. Open the ChatBot app on your preferred device
2. Start chatting with the virtual assistant in the available chatroom
3. Experience seamless communication with the app's user-friendly interface
